# MotorBridge 0.4.1 Release Test Note

Date: 2026-06-02

## Summary

Aligns the public ABI, Python binding, C++ binding, and documentation API
surface at version 0.4.1. Adds ABI metadata discovery and completes C++ wrapper
parity with Python for RobStride helper methods.

## Version Alignment

| Component | Version |
|---|---|
| Git release tag | `v0.4.1` |
| Rust workspace crates | `0.4.1` |
| Python package | `0.4.1` |
| C++ package metadata | `0.4.1` |

## Key Changes

### Added

- C ABI metadata functions `motor_abi_version()` and
  `motor_abi_capabilities_json()`.
- Python metadata helpers `motorbridge.abi_version()` and
  `motorbridge.abi_capabilities()`.
- C++ metadata helpers `motorbridge::abi_version()` and
  `motorbridge::abi_capabilities_json()`.
- `bindings/api_surface.json` as the canonical binding/API surface list.
- API surface regression coverage for the binding parity metadata.

### Changed

- Completed C++ wrapper parity with Python for RobStride helper methods:
  `robstride_ping_host_id`, `robstride_get_param_f32_host_id`,
  `robstride_get_fault_report`, and `robstride_set_active_report`.
- Added C++ RobStride ID range validation to match Python binding behavior.
